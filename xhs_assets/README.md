## Boundary

These files are not part of the core `takeaway-skill` workflow.

They are kept here only as public promotional assets for the current release package.

Do not place private drafts, unpublished client/student material, local screenshots, private research notes, or internal workflow captures in this folder.

If an asset is only a working draft or contains platform-specific private strategy, move it out of the public repository before release.

# Changelog

All notable public changes to `takeaway-skill` are documented here.

This repository is maintained as a public, lightweight Skill/workflow package. Private research material, private prompt chains, and third-party source archives are intentionally not included.

## Public v2.0 Package

Public package update focused on clearer loading, safer output boundaries, and a better beginner path.

### Added

- Added clearer AI-assisted loading instructions for Codex, Claude Code, and similar coding agents.
- Added a public-safe output path through `takeaway_is_here/`.
- Added guidance for when public-safe distilled results may be mirrored into `site/index.html`.
- Added a public showcase shell and demo materials.
- Added contributing guidelines in English and Chinese.

### Changed

- Clarified that `takeaway-skill` is a Skill/workflow layer, not a package installer, app installer, or environment setup script.
- Clarified that the public repository should not archive third-party screenshots, recordings, private notes, or source material packages.
- Clarified the difference between the lightweight public package and the stronger internal/social-media workflow.
- Moved loading guidance before demo material so first-time users can start faster.

### Maintenance Notes

Early public usage showed that some readers liked the idea but did not always know how to load or use a Skill repository. This update makes the first step more direct: ask a coding agent to read `README.md` and `skill/SKILL.md`, confirm the Skill is readable, and stop before running unnecessary setup commands.

The public package also keeps a clear boundary: it teaches reference distillation, but it does not ship private research archives, copied surface designs, or unauthorized source material.
